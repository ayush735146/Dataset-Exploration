## Objective
Explore a dataset with Pandas before model building using `shape`, `columns`, `info()`, `describe()`, `head()`, and `tail()`.

## Dataset
Iris Dataset with 150 observations and 5 columns:
- sepal_length
- sepal_width
- petal_length
- petal_width
- species

## Tools
- Python
- Pandas
- Jupyter Notebook

## How to Run
1. Install Python 3.
2. Install dependencies: `pip install -r requirements.txt`
3. Open Jupyter Notebook.
4. Run `Day_17_Dataset_Exploration.ipynb`.

## Key Observations
- 150 rows and 5 columns.
- Four numerical columns and one categorical column.
- Three species are represented.
- No missing values.
- Petal measurements vary noticeably between species.
